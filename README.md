# options-strategy-analyzer
A Python project that uses the Black-Scholes model to analyze option strategies.

## Features
- Black-Scholes option pricing
- Delta, Gamma, Theta, Vega calculations
- Implied volatility estimation
- Strategy payoff analysis
- Profit/loss calculations at expiration

## Technologies Used
- Python
- SciPy
- NumPy
- Matplotlib
